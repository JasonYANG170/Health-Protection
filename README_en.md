## Features
- ✅Daily poetry
- ✅Daily English
- ✅Daily weather
- ✅Daily music
- ✅Daily horoscope
- ✅Daily news
- ✅ Turn on Windows dark mode regularly
- ✅ Limit app usage time
- ✅ Automatic reminder at startup

## Build
```
qt打开src的.pro文件选择MinGW或MSVC2019编译运行即可
```

## Instructions for use of official version and BETA version
1. Set up custom prompt content.

2. Click Save Text to save (if you choose Daily Poetry, Daily English, please ignore this step)

3. Click Auto-Start to set the auto-start function.

4. You can enable automatic closing so the application exits after displaying its notification at each startup.

(This is a major operation. If you need to reset the content after using this function, please click to disable automatic closing within 5 seconds after opening the program next time.)

## Insider Preview Instructions for Use
1. This is a new UI reconstruction version developed by QT, which requires you to have certain CPP language and GUI development experience.

2. You need to download the QT development tools and configure the QT environment by yourself.

3. Open the file with the ".pro" suffix in the Insider Preview compressed package and debug it in QT.

## Support environment
1. Non-lite version, operating system WindowsXP or above (Windows 10 or above recommended)

2.64-bit operating system
